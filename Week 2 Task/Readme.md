# Emoji Search App

## Overview
This application allows users to search for emojis by keyword and copy them to the clipboard. It features a clean and intuitive user interface, making it easy to find and use emojis.

## Features
- Search for emojis using keywords.
- Copy emojis to the clipboard with a single click.
- Responsive design for mobile and desktop users.

## Usage Instructions
Type a keyword related to the emoji you want to find in the search bar.
Click on the emoji displayed in the results to copy it to your clipboard.
An alert will confirm that the emoji has been copied.

## Technologies Used
- **HTML**: For the structure of the application.
- **CSS**: For styling and layout.
- **JavaScript**: For functionality and interactivity.
